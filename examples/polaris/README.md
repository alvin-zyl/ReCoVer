# Polaris (ALCF)

The paper's experiments ran on [Polaris](https://www.alcf.anl.gov/polaris) at the Argonne Leadership Computing Facility: up to 128 nodes with 4 NVIDIA A100 40 GB GPUs each, scheduled with PBS.

The job scripts and configurations for these runs (3D parallelism with a 7B model, HSDP with a 1B model) will be added here.
